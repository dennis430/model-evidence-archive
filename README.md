# model-evidence-archive

Cryptographically anchored longitudinal archive of model responses to synthetic evidential-reasoning probes.

Records authentic collector-observed responses. Does not invent historical observations or claim provider-origin authentication unless present.

## Status

Experimental. Collection requires authorized API access. If fewer than three frontier models are accessible, authentic available collection is published with coverage disclosed. See companion source-dependence for analytical core and bundles.

## Contents

- Frozen public historical panel of 12–20 original short synthetic probes (evidential behavior: duplicated support, independent measurements, missing lineage, contradictions, coverage failures, authenticity-vs-truth, unjustified attribution).
- Paired transformations and positive controls.
- Collection harness (GitHub Actions) with budget limits, idempotency, and verification.
- Public records, verification instructions, static comparisons.
